About the Project

This project demonstrates how to host and automate deployments of a static website on Amazon S3 using GitHub Actions. Every time I push an update to GitHub, the website is automatically redeployed to AWS — no manual uploads required.

Amazon S3

Used for reliable, scalable static website hosting in the AWS Cloud.

GitHub Actions

Implements a CI/CD pipeline that automatically syncs updates from GitHub to S3.

Secure Setup

IAM user credentials stored in GitHub Secrets — following AWS security best practices.

How the CI/CD Pipeline Works

  1. 💻 Code changes are pushed to the main branch on GitHub.
  2. ⚙️ GitHub Actions triggers a workflow that logs into AWS via IAM credentials.
  3. ☁️ Files from the website/ folder are synced to the S3 bucket.
  4. 🌍 The new version of the website goes live automatically.
